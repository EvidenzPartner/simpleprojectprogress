# SimpleProjectProgress – GitHub-Pages-Dateien

## Enthaltene Dateien

- `index.html` – Startseite
- `style.css` – gemeinsames Design
- `datenschutz/index.html` – Datenschutzerklärung
- `impressum/index.html` – Impressum
- `support/index.html` – Support
- `assets/simpleprojectprogress-logo.png` – Logo

## Vor dem Hochladen zwingend ersetzen

Suche in allen HTML-Dateien nach:

- `DEINE-EMAIL-ADRESSE`
- `VOLLSTÄNDIGE POSTALISCHE ANSCHRIFT`
- `STRASSE UND HAUSNUMMER`
- `POSTLEITZAHL UND ORT`

Ersetze diese Platzhalter durch deine tatsächlichen Angaben.

## Hochladen über die GitHub-Oberfläche

1. Repository `simpleprojectprogress` öffnen.
2. `Add file` → `Upload files`.
3. Den Inhalt dieses Ordners hochladen. Die bestehende `index.html` darf ersetzt werden.
4. Änderungen mit `Commit changes` speichern.
5. Unter `Settings` → `Pages`:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
   - `Save`
6. Nach wenigen Minuten ist die Seite erreichbar unter:
   `https://DEIN-GITHUB-NAME.github.io/simpleprojectprogress/`
